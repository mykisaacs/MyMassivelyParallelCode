# MyMassivelyParallelCode

This repository is a personal learning space for exploring massively parallel programming concepts from the book "Programming Massively Parallel Processors: A Hands-On Approach, 4th Edition".

The goal is to document my own experiments, exercises, and reference implementations as I work through the material and build practical understanding of GPU and parallel computing concepts.

## Purpose

This repo is intended to hold:

- C implementations and experiments
- C++ examples and utilities
- Python scripts for data generation, analysis, or interfacing with the main code
- Java-based examples or tools that help interact with or support the core projects
- notes, experiments, and small code samples connected to parallel processing topics

## Scope

I am learning about:

- CUDA and GPU architecture concepts
- parallel algorithm design
- memory hierarchy and optimization
- data parallelism and thread-level execution
- performance measurement and profiling
- practical examples inspired by the book

## Repository structure

This repo will grow over time as I add examples and experiments. The focus will remain on understanding and applying the ideas from the textbook through hands-on code.

## Notes

- The main work will primarily use C and C++ for performance-oriented implementations.
- Some supporting or external code may be written in Python and Java to interact with the main code, automate workflows, or process results.
- This repository reflects my own learning process and is not intended to be a polished or production-ready framework.
